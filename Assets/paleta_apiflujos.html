Texto Principal (Body): Utilizado para el contenido general de la aplicación. La tipografía principal (Headings y UI) es Poppins para dar un toque moderno y geométrico, mientras que Manrope se usa para cuerpos de texto extensos y data tabular densa. Alto Contraste — Paleta extendida (WCAG AAA ≥ 7:1 sobre #000)

Estos tonos están curados para superar contraste AAA (≥7:1) sobre fondo negro. Úsalos para etiquetas de categoría, indicadores de canal y elementos diferenciales en la UI de alto contraste. **Interactividad**: Los botones en este modo invierten colores al hover para una respuesta táctil/visual inequívoca.

Modo Accesibilidad — Paleta Okabe-Ito

Investigación aplicada: Esta paleta es distinguible por protánopes, deuteránopes y tritánopes. Se evitan las combinaciones conflictivas y se integran estos tonos en los temas claro/oscuro para mejorar el contraste semántico global.
